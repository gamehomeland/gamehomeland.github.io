# 图像转换与蓝图导出流程

## 输入参数

必要输入为图片、摆放方向和成品长边。图片保持比例；过细长或单轴不足的图会通过留白补足可构造的画布，界面和完整包都会提示。透明区域铺白底，透明像素中未显示的 RGB 不参与配色。

支持 PNG、JPG、静态 WebP 和 GIF；输入不超过 50 MiB、800 万像素。GIF 在解码前截取首个图像块，保留画布、调色板、透明色、交错与位置；预览和导出使用同一份单帧图像。后续帧不播放、不解码。APNG、动画 WebP 暂不支持。文件头验证与浏览器实际解码分开，尺寸超限或首帧损坏时给出错误。图片不会上传。

## 1. 网格规划与布局选择

`image.ts` 分析图片颜色、轮廓与像素特征，结合成品尺寸及家具预算计算网格。像素画使用适当的最近邻采样，其他图片使用面积取样。采样网格与原图像素数量分别计算。

如果单格尺度落在实际拼布可用范围内，优先构造普通布局。相邻同色区域尝试合成 8、4、2、1 格的正方形家具；只有可用规格和缩放范围都成立才合并。合并区域必须符合家具的实际形状与合法缩放。

如果需要更细的可见格，则构造微缩布局。每块家具保持合法实体尺寸，通过分区姿态和遮挡形成图案。工具检查实体包围盒与每格可见性，不仅检查正面投影。

墙面长边允许 1～96 米，地面 1～200 米。默认根据缩略分析中的轮廓变化和颜色信息量决定采样密度；纯色图可以简化，细节丰富的图保留更多格。玩家也可以直接提供包含基座的家具预算。成品还需满足目标地块的可用面积、库存及保存条件。

自动规划是本工程的启发式策略，不是游戏容量公式：128 边长分析图中，统计 RGB 通道差超过24的相邻变化数，并结合颜色分布熵与长宽比估计目标网格；随后继续按实体尺寸、节点数、文件字节和实际家具成本检查。参数可由二次开发者调整，但需要重新对照实际图片质量。

输出保护由对象结构推导。若拼布数为 `n`、完整挂接树基座数为 `b`，节点数是 `3n + 4b + 1`。`budget.ts` 在解析器的节点和字节保护范围内求得最大可处理数量；当前对应最多81,123块拼布及82,780件含基座家具。该数值属于工具处理边界，不作为默认用量，也不代表游戏允许数量。

## 2. 在颜色质量和家具预算间选择

`color.ts` 为目标色搜索配方并评价全图。普通布局会生成不同叠层成本的候选，结合合并后的实际家具数量选择；基座也计入预算。预算不足时降低网格密度，而不是生成一半图案或漏掉家具。

处理器负责执行相同算法。当前网页和桌面在本机 CPU 的 Web Worker 运行，不依赖远程服务或显卡。页面主线程保留输入和取消操作，取消会终止当前 Worker。

## 3. 写入游戏节点

`layout.ts` 计算每块家具的型号、缩放、四元数和位置；`component.ts` 创建基座与挂接树；`codec.ts` 写入 V7 文件和校验值。

导出以 Holder 局部组件为根。实例 ID 唯一，家具资源 ID 必须存在于当前资料。所有拼布采用资源允许的等比缩放。根基座可选择显示样式，但不会为了隐藏基座而删掉结构。

## 4. 输出文件回读与验证

```text
原图 → 网格与颜色候选 → 家具布局 → 二进制蓝图
                                      ↓
                         重新解码与合成变换
                                      ↓
                   几何、数量、可见性、材料核对
                                      ↓
                      拼布预览 + 清单 + 完整包
```

文件回读用于检测预览与序列化结果不一致的情况，包括方向补偿错误、坐标重复缩放、舍入后越界或两个格被同一块家具遮住。

微缩可见性对每格中心及四个内侧角点共 5 点作观察射线与家具平面的求交，比较最近可见家具是否就是该格。该检查覆盖指定观察方向的五个采样点；其他视角、子像素遮挡和游戏材质效果需要另行验证。

## 5. 交付文件

| 文件                | 用途                     |
| ------------------- | ------------------------ |
| 家园蓝图.blueprintx | 游戏导入的局部组件       |
| 效果预览.png        | 从蓝图回读得到的拼布效果 |
| 家具清单.txt        | 拼布与基座的实际数量     |
| 使用说明.txt        | 尺寸、方向、导入步骤     |

同一输入与参数生成相同蓝图；ZIP 使用固定时间字段，便于开发者做可重复的文件差异检查。

## 6. 修改参数时的行为

切换图片、尺寸、方向、数量上限或基座显示后，旧结果立即失效。下载结果始终关联当前输入参数。

生成中的旧任务被取消或图片被更换后，即使旧异步操作较晚返回，也不能覆盖新结果。下载只在当前任务全部校验成功之后出现。
