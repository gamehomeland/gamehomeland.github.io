# 蓝图字段字典与读取边界

本章按文件的读取顺序解释第7版字段，包括图片转换没有用到的场景、笔刷和灯光。偏移均从 **0** 开始，整数和浮点数均为小端序。`u8/u16/u32` 为无符号整数，`f32` 为 IEEE 754 单精度。

字段布局与业务语义分别记录验证状态。没有可靠证据的字段保留原值与偏移，不随意命名为隐藏、锁定或权限。字段字典覆盖的结构多于应用编解码器；具体读写与编辑范围见[解析覆盖](18-coverage-and-3d.md)。

## 一、完整文件的顺序

```text
global: u8
formatVersion: u32
若 global=1：场景参数 → 地表绘制块 → 植被绘制块
根节点头与变换 → 子节点树（前序遍历）
完整性校验：16字节
```

| 文件偏移    | 长度 | 参数           | 说明                                                  |
| ----------- | ---- | -------------- | ----------------------------------------------------- |
| 0           | 1    | global         | 0为局部组件，1为全局场景；由文件头判定                |
| 1           | 4    | formatVersion  | 本章核对值为7，其他版本不套用这些偏移                 |
| 5           | 可变 | 场景块或根节点 | 局部文件直接进入根节点；全局先读三个场景块            |
| 文件末尾−16 | 16   | checksum       | 前面全部字节的 MD5 循环左移1字节，再逐字节 XOR `0x33` |

校验只能检查文件内容是否完整，不验证资源存在、玩家库存、摆放权限或作者身份。任何参数修改后都必须重新计算；检查工具严格比较全部16字节。

## 二、全局场景固定部分

以下是文件的绝对偏移，固定部分结束于46。场景尺寸、建筑包围盒与家具坐标使用文件坐标单位，显示为米前需要执行相应换算。

| 偏移   | 类型   | 参数                | 用途                                                                  |
| ------ | ------ | ------------------- | --------------------------------------------------------------------- |
| 5、9   | f32 ×2 | sceneExtent         | 根平面的两轴半尺寸（文件坐标单位）                                    |
| 13～36 | f32 ×6 | buildingLocalBounds | 相对场景根的建筑局部包围盒；顺序为 minX、minY、minZ、maxX、maxY、maxZ |
| 37     | u32    | nextInstanceId      | 实例编号分配的后续边界，插入节点会推进编号                            |
| 41     | u8     | withVersion         | 保存版本标记                                                          |
| 42     | u32    | saveVersion         | 启用版本标记时推进的保存计数；否则写0                                 |
| 46     | 可变   | groundData          | 下一节地表块                                                          |

**全局头不是固定222字节。**只有地表三层均无压缩数据、植被类型数为0的已核对子集，节点树才从222开始。`codec.ts` 的可编辑整屋输入限定该子集；`blueprint-structure.ts` 的原整屋遍历与只读检查器均按实际块长度推进。合并保留已有绘制块，不将其转换为可编辑地形。

## 三、地表绘制块

此节偏移相对地表块起点（通常是文件46）。当前保存路径写子格式版本2。

| 相对偏移 | 类型   | 参数                  | 说明                                           |
| -------- | ------ | --------------------- | ---------------------------------------------- |
| 0        | u32    | groundVersion         | 当前为2；旧版1的子层布局不同                   |
| 4        | u32    | layerCount            | 当前保存3层；已核对加载范围不超过3             |
| 8、12    | u32 ×2 | gridWidth、gridHeight | 绘制网格尺寸，不是家具数量                     |
| 16～27   | f32 ×3 | scale                 | XYZ 三轴缩放，与旋转、位置一起交给节点局部 SRT |
| 28～43   | f32 ×4 | rotation              | 四元数XYZW，保存前转换到场景根局部空间         |
| 44～55   | f32 ×3 | position              | 场景根局部位置XYZ                              |
| 56起     | 可变   | layers                | 按layerCount依次读取                           |

版本2每层的固定头为21字节，后面紧跟本层压缩数据：

| 层内偏移 | 类型                  | 参数                  | 说明                                            |
| -------- | --------------------- | --------------------- | ----------------------------------------------- |
| 0        | u32                   | resourceId            | 地表绘制资源编号，关联 ID_CustomBrush 的 Type=2 |
| 4        | u32                   | instanceId            | 地表对象实例编号，不能替代家具目录编号          |
| 8        | u32                   | layerOrder            | 层次序号，默认依次0、1、2                       |
| 12       | u32                   | compressedBytes       | 随后压缩数据的字节数                            |
| 16       | byte ×5               | compressionProperties | LZMA属性块；不能按一个f32解释                   |
| 21       | byte ×compressedBytes | compressedData        | 本层网格的压缩数据                              |

空层保留次序，两个首字段、压缩长度及属性写0。版本1每层先读三个u32；首字段非0时继续读 `gridWidth × gridHeight` 字节。版本2须按独立的压缩长度字段解析。

解压后的每格为一个 u8 绘制权重，进入渲染数据时除以255.0。检查器可通过 `--decode-grids` 有界解压：检查5字节LZMA属性、字典上限、网格上限和准确输出长度。原生创建路径要求格数小于1,048,576。无压缩数据的空层不解压。结构检查及合成样本通过，不等于已有全部玩家绘制数据的实景验收。

## 四、植被绘制块

从地表块结束位置继续读取，不使用固定绝对偏移。

| 相对偏移 | 类型   | 参数                  | 说明                      |
| -------- | ------ | --------------------- | ------------------------- |
| 0        | u32    | foliageVersion        | 当前为1                   |
| 4、8     | u32 ×2 | gridWidth、gridHeight | 植被覆盖网格              |
| 12       | u8     | typeCount             | 类型数量，已核对上限64    |
| 13       | u32    | instanceId            | 这块植被对象的实例编号    |
| 17～28   | f32 ×3 | scale                 | 植被节点局部 XYZ 三轴缩放 |
| 29～44   | f32 ×4 | rotation              | 四元数XYZW                |
| 45～56   | f32 ×3 | position              | 根局部位置XYZ             |
| 57       | 可变   | typeTable、grid       | typeCount为0时全部省略    |

非空时先写固定320字节类型表：64个u32资源编号（256字节），再写64个u8索引映射。后面是 `gridWidth × gridHeight × 2` 字节的网格：每格第一个字节用于类型映射，第二个字节的具体覆盖/密度语义尚未确认。不能擅自按百分比或高度显示第二字节。

## 五、节点类型和头部

节点树使用前序遍历。先读节点头和变换，再递归读取声明数量的直接子节点。下表长度不含子树。

| type | 名称                | 头及变换长度 | 与普通模型的差别                      |
| ---- | ------------------- | ------------ | ------------------------------------- |
| 0    | Model               | 49或57       | 按资源选择等比或非等比变换            |
| 1    | BrushModel          | 43           | u16笔刷资源、u16掩码                  |
| 2    | SubGroupModel       | 54或62       | 普通字段外多1字节状态与4字节组字段    |
| 3    | GroupModel          | 49或57       | 预制体/组合模型，不是可省略的分组注释 |
| 4    | LightModel          | 可变         | 自带长度、184字节SDK参数、两条字符串  |
| 5    | PlaneContainer      | 空5，非空37  | 平面挂接容器                          |
| 6    | SlotContainer       | 空5，非空37  | 点/槽挂接容器                         |
| 7    | MultiPlaneContainer | 空5，非空37  | 多平面挂接容器                        |
| 8    | HolderModel         | 49或57       | 组件根持有者，资源可为`0xFFFFFFFF`    |
| 9    | CascadeBrushModel   | 44           | 笔刷字段外多1字节状态                 |

### 普通模型：0、3、8

| 相对偏移 | 类型       | 参数       | 含义                                                                           |
| -------- | ---------- | ---------- | ------------------------------------------------------------------------------ |
| 0        | u8         | type       | 节点类型                                                                       |
| 1        | u32        | flags      | type0 的 bit0 是传送家具方向反转状态；其他位及其他节点分支保留原值，不扩大解释 |
| 5        | u32        | instanceId | 当前树内的一件对象，不是库存家具编号                                           |
| 9        | u32        | resourceId | 表现资源编号，关联模型/预制体/挂点定义                                         |
| 13       | u8         | builtin    | 内建模型标志，预制体自己的模型与外部挂接家具据此区分                           |
| 14       | u8         | detail     | 已有Detail样式选择，不是任意RGB、透明度或品质                                  |
| 15       | u16        | childCount | 直接子节点数，不含更深层后代                                                   |
| 17       | 32或40字节 | transform  | 见后面的变换定义                                                               |

### 子组：2

到detail为止与普通模型相同。之后：

| 相对偏移 | 类型       | 参数                           | 含义                                     |
| -------- | ---------- | ------------------------------ | ---------------------------------------- |
| 15       | u8         | subgroupHasMultiPlaneContainer | 是否具有多平面挂接容器                   |
| 16       | u32        | subgroupTagMask                | 来源 UserData 标签掩码；不是分组实例编号 |
| 20       | u16        | childCount                     | 直接子节点数                             |
| 22       | 32或40字节 | transform                      | 同样由资源决定缩放维数                   |

由3D节点创建子组时，UserData 中的 `combine` 子串决定是否建立 MultiPlaneContainer。标签 `01`、`02`、`03`、`wall`、`roof` 分别映射位值1、2、4、8、16，可组合；无匹配时写 `0xffffffff`。这些标签的命名来自资源分类，不应解释为玩家权限。

### 笔刷：1、9

| 相对偏移   | 类型   | 参数          | 含义                                                          |
| ---------- | ------ | ------------- | ------------------------------------------------------------- |
| 0          | u8     | type          | 1或9                                                          |
| 1          | u32    | instanceId    | 对象实例编号                                                  |
| 5          | u16    | brushResource | 笔刷资源编号，宽度不是u32                                     |
| 7          | u16    | mask          | 笔刷掩码原值                                                  |
| 9，仅type9 | u8     | cascadeField  | 兼容字段；构造默认值1，两条已核对加载路径跳过，业务名称未确认 |
| 9或10      | u16    | childCount    | type1在9，type9在10                                           |
| 11或12     | f32 ×8 | transform     | 两类均使用等比变换                                            |

### 挂接容器：5、6、7

`type:u8 → index:u16 → childCount:u16`。`index` 是父资源的挂面/挂点索引。只有childCount非0才继续写32字节变换，再写子树。空挂面多写变换会使后续所有字段错位。

### 灯光：4

| 相对偏移 | 类型          | 参数               | 含义                                                      |
| -------- | ------------- | ------------------ | --------------------------------------------------------- |
| 0        | u8            | type               | 4                                                         |
| 1        | u16           | nodeBytes          | 本节点头、路径和变换总长，不含子树                        |
| 3        | u32           | flags              | 当前保存路径写0                                           |
| 7        | u32           | instanceId         | 灯光实例编号                                              |
| 11       | byte ×184     | lightSDKParameters | SDK兼容灯光结构；已确认字段见下表，未命名区域保留原始字节 |
| 195      | NUL终止字符串 | materialPath       | 材质路径，最大259字节内容加终止字节                       |
| 可变     | NUL终止字符串 | maskPath           | 遮罩路径，同样有终止字节                                  |
| 可变     | u16           | childCount         | 路径后紧跟子节点数量                                      |
| 可变     | f32 ×8        | transform          | 等比变换                                                  |

两条路径为空时最短231字节；两条均为259字节内容时为749字节。SDK块包含混合类型字段，不能按46个同类型浮点数整体解释。检查器保留完整184字节十六进制，也提供u32/f32双视图供研究；这不是已命名的46个参数。

#### SDK块内部：偏移从184字节块起点计算

渲染器运行时使用344字节扩展结构，蓝图保存184字节兼容结构。两者通过显式字段映射转换，不能直接截取前184字节。下表依据兼容转换、JSON字段读取和调用者交叉对应，名称保留原参数键；没有确认的范围或单位不凭名称推导。

| 块内偏移                | 类型     | 参数或含义                                                              |
| ----------------------- | -------- | ----------------------------------------------------------------------- |
| 0                       | u32      | Type，当前核对到分支0、1、2                                             |
| 4                       | vec4     | BaseColor；JSON创建路径会结合强度处理，不能直接当最终显示RGB            |
| 20                      | f32      | Intensity                                                               |
| 24、28                  | f32×2    | Type0：Radius/PLInnerRadius；Type1：Radius/Length；Type2：Length/Cutoff |
| 32～79                  | 48字节   | 保留；其中部分分支复制32/36，但最终消费语义未确认                       |
| 80                      | u32      | IsDynamic                                                               |
| 84、88                  | f32×2    | ShadowStrength、DepthBias                                               |
| 92                      | u32      | TextureSize                                                             |
| 96                      | f32      | NearPlane                                                               |
| 100                     | u32      | ForPlayer                                                               |
| 104～107                | 4字节    | 保留                                                                    |
| 108                     | 64位地址 | PLMaterialPath 的运行时地址副本，不可离线解引用                         |
| 116、120、124           | f32×3    | PLIntensityAtten、PLFrequency、PLFlashDarkness                          |
| 128                     | 64位地址 | PLTextureMaskPath 的运行时地址副本                                      |
| 136                     | u32      | ForRTX                                                                  |
| 140                     | 64位地址 | TextureIES；部分复制路径清零                                            |
| 148                     | u32      | UseIESIntensity                                                         |
| 152、156、160、164、168 | f32×5    | IESIntensityScale、SourceLength、MaskLength、MaskScale、MaskOuterLength |
| 172                     | vec3     | MaskPosPow                                                              |

文件末尾两条字符串用于重新建立材质和遮罩路径引用。184字节块内的进程地址不具备跨进程、跨机器意义。扩展结构中的 StartTime/EndTime不在该兼容映射中；蓝图未保存全部运行时灯光参数。

可机读字段、模块哈希及函数RVA见 `docs/blueprint-semantics.json`。检查器输出已命名字段和未知字节两部分；剩余未知区间共52字节。

## 六、变换的全部分量

等比变换32字节：

| 变换内偏移   | 参数           | 解释                               |
| ------------ | -------------- | ---------------------------------- |
| 0            | scale          | 等比缩放，必须结合家具目录允许范围 |
| 4、8、12、16 | qx、qy、qz、qw | 四元数XYZW，不能直接当欧拉角       |
| 20、24、28   | px、py、pz     | 相对父对象/挂面的平移XYZ           |

非等比变换40字节：前12字节为sx、sy、sz；其后16字节四元数、12字节平移。是否多出两个缩放分量由资源配置决定，**文件头不自描述缩放维数**。任意资源解析需要对应的`ID_Model`非等比字段；解析器必须依据资源配置确定布局。

物体的实际世界位置还涉及父对象旋转、挂面定义和编辑器导入朝向。变换合成须遵循父子坐标约定，结果应通过蓝图字节回读验证。

## 七、局部蓝图未包含的数据

图片的文件名、原始像素、RGB目标、Lab色差、自动网格规则和工具的家具预算不写入游戏节点字段。真正写入的是资源、样式、层级和变换。

局部拼布组件也不包含整张地图的太阳方向、天气、时辰、滤镜与环境探针。即使全局文件含有LightModel，也不能把灯光SDK块当成整个场景的天气配置。相关场景资料见[光照与场景](11-lighting-and-scene.md)。

## 八、只读检查工具

```sh
python tools/inspect_blueprint.py 图案.blueprintx --output 字段解读.json
# 分析目录外资源时提供对应的资源表，避免误判非等比变换：
python tools/inspect_blueprint.py 场景.blueprintx --models ID_Model.txt --output 字段解读.json
python tools/inspect_blueprint.py 场景.blueprintx --models ID_Model.txt --decode-grids --output 地表解读.json
```

报告逐项给出字段路径、绝对字节偏移、长度和原值。默认只记录压缩地表长度与摘要，显式加 `--decode-grids` 才有界解压；未知SDK字节原样展示。遇到未知版本、缺资源缩放规则、截断、异常长度或多余尾字节直接拒绝，不尝试修补原文件。报告schema为2，游戏文件版本仍为7。

只读检查器覆盖的结构多于图片转换核心，但它只读、不导出任意场景；不能用它的成功结果承诺游戏必定接受文件。

## 九、核对依据和仍未知的部分

结构交叉核对了保存与加载两侧：`_SaveBlueprint`、`_LoadBlueprint`、`_LoadBlueprintNode`、`_SaveModel`、`_SaveSubGroupModel`、`_SaveBrushModel`、`_SaveCascadeBrushModel`、`_SaveLight`、`_SaveContainer`，以及`AppliqueModel::Serialize`和`FoliageCoverModel::Serialize`。

未确认的部分：植被每格第二字节的精确用途、级联笔刷兼容字节的历史业务名称、flags未定义位、灯光块32～79及104～107字节、部分灯光枚举的完整范围与单位。字段名与结构已确认的部分，也仍需最小游戏样例验证修改、保存与重载。
