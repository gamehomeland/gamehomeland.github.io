# 使用说明

本页面提供图片转蓝图、家具布置和地下室编辑的基础功能。“技术与开发”包含实现原理与扩展文档；日间、夜间主题设置保存在本机。

## 图片转蓝图

1. 选择图片，或点击“加载示例”。支持 PNG、JPG、静态 WebP 和 GIF，单文件不超过 50 MiB、800 万像素。GIF 仅处理第一帧。
2. 选择墙面画或地面图案，填写成品长边。墙面支持 1～96 米，地面支持 1～200 米；另一边按图片比例计算。
3. 点击“生成蓝图”，核对效果、尺寸和家具用量。
4. 下载完整包，按家具清单准备库存，在游戏的**局部组件入口**导入。

采样格数、配色和拼布规格自动适配。透明区域填充白底；必要的画布留白会在结果中说明。“更多选项”可设置家具预算、整体操作基座及彩色琉璃试验配色。

普通布局可合并同色区域，并使用透明拼布叠层改善配色。微缩布局通过倾角与遮挡形成较小的可见网格，适合从墙面正前方或地面上方观察。家具色域、纹理和游戏光照会影响最终效果。

## 三维查看

生成图片蓝图后，选择“3D 预览”可查看从文件读取的家具实例。支持旋转、缩放、平移、视角切换、结构线和放大查看；观察操作不修改下载文件。

“3D 家园布置”的“单件预览”可打开自包含 GLB 文件，查看材质、样式和尺寸。网页与桌面已内置部分家具、地下室模型和贴图，按需加载；额外 GLB 应内嵌几何及纹理。

操作方式：拖动旋转、滚轮或双指缩放、右键拖动平移。WebGL 不可用时，图片导出、二维预览和下载仍可使用。

## 家具布置

在“3D 家园布置”中选择“在线布置”，从内置的部分家具库添加模型，或通过“打开模型文件”选择与资源目录匹配的 GLB。项目提供 36 件普通家具的导出绑定；其他符合格式要求的 GLB 可用于单件预览。

选中家具后，通过操作轴或数值表单调整位置、旋转和缩放。可执行复制、删除、落地、撤销和重做；操作范围由相应家具的资源配置决定。吸附步长为移动 0.1 米、旋转 15 度、缩放 0.05。

“选择户型 / 地块布局”提供七档设计规格、五个社区的 108 处地块及私宅七个分区。选择后，编辑器检查家具和地下室的完整水平投影；切换范围不会自动移动现有家具。“放大工作区”可扩大操作画面。

## 地下室与地下家具

1. 扩建已有家园时，先点击“载入原整屋”，选择游戏保存的完整蓝图，再点击“连通原房间”。原房间与家具只读显示；没有显示模型的家具保留为位置标记。
2. 选择与原房间相同的 4 米或 8 米规格及工作层，点击绿色可扩建格。预览同步打开相接的墙面或地板；也可展开“按坐标操作”。
3. 使用“回填”删除新增单元。“当前层剖面”用于观察下层，剖面设置只影响预览。
4. 通过“新家具位置”选择新增家具的地板；工程内的可编辑家具可在“所在区域”中迁移，也可使用“选择地板”点击目标房间。原整屋中的家具仅供只读预览。
5. 保持“合并到现有整屋”模式，点击“合并导出蓝图”或“导出完整包”。画布与工程只编辑新增部分，原布置作为底图保留。
6. 仅在准备替换整个家园时，选择“新建整屋”。地下家具按地板挂接关系一同保存。

4 米组件有四种材质，8 米组件有两种材质。每种资源包含 24 个连通形态；模型和贴图按需加载。桌面版自动读取随包模型。单文件离线 HTML 可通过“打开地下室模型”选择源码包中的对应 GLB。模型缺失会明确显示为结构占位。

回填新增房间前，应先移走其中的家具。与原房间连通时，原家具保持世界位置、朝向、缩放、编号和子挂接；原墙面或地板消失后，挂件会转挂到可用地板。向下打通不会自动降低原家具高度，必要时可在游戏内调整。4 米与 8 米组件可分区设置，不能重叠或直接连接。

## 工程保存与恢复

“保存工程”生成 `.homeland.json` 文件，保留家具、地下室和地块选择，用于继续编辑。当前标签页会暂存有效工程，刷新可恢复；关闭页面前应另存工程文件。

“打开工程”可读取工程文件，以及本编辑器支持的局部或整屋蓝图。模型文件缺失时保留对象数据，稍后加载模型即可补齐预览。

游戏保存的完整家园应通过“载入原整屋”打开。原整屋仅保存在当前页面内存及合并完整包中，不写入标签页草稿；刷新后先恢复新增工程，再重新选择同一份原始整屋。

## 导出类型与游戏入口

| 布置内容                           | 文件类型 | 游戏导入入口 |
| ---------------------------------- | -------- | ------------ |
| 图片转拼布                         | 局部组件 | 局部组件入口 |
| 不含地下室且未合并原整屋的家具布置 | 局部组件 | 局部组件入口 |
| 含地下室的家具布置                 | 整屋蓝图 | 整屋蓝图入口 |
| 合并到原整屋的新增布置             | 整屋蓝图 | 整屋蓝图入口 |

**整屋导入作用于整个家园，选择一个私宅分区也不表示只替换该分区。** 合并导出保留所选原文件的家具、地下室、灯光、地表涂绘和植被，再加入当前工程；新建整屋只包含当前工程。导入前保存现有布置，并按文件类型选择入口。

合并时，原蓝图与当前户型必须具有相同的整屋范围。同规格房间可横向或上下连通，不能重叠或错位连接。深层新增单元可以通过原房间连接地表，无需重复创建上方房间。重复修改同一新增工程时，始终选择最初的原蓝图作为底图，避免重复追加。完整包会包含该原蓝图，便于继续编辑。

图片完整包包含蓝图、效果预览、家具清单和使用说明；布置完整包包含蓝图、工程文件、家具清单和使用说明。

导入后核对数量、位置和方向，确认摆放并在游戏中保存，再重新进入检查。整体移动图像组件时，应保持挂接结构完整。

## 使用范围

网页采用中性照明，未模拟游戏天气、地形碰撞和玩家通行。库存、等级、分类容量、单种家具上限及保存权限由游戏核对。文件与几何校验通过不等同于游戏内保存验收通过。

具体边界见[家园限制](10-game-limits.md)、[地块布局](22-land-layouts.md)和[地下室组件](23-basement-and-terrain.md)。
