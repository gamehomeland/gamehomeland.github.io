# 扩展材质配色

## 基础配色与色域

拼布目录中的 71 种不透明底色作为基础。普通布局增加灰1透明叠层后有 426 个配方，在当前中性显示模型下得到 412 个不同的 8 位 RGB；配方数量不等于色域宽度。微缩底层使用 71 种底色。

灰1主要提高明度、降低饱和度。重复叠加同一种透明层主要改变明度，无法覆盖全部缺失色相。游戏染色表也没有为这些拼布增加其他 Detail。

五种琉璃的挂面定义是正方形。七巧大板的实际网格包含弧线和斜边，名称中的“2米/4米”不能直接当成正方形边长。两类材料都不能复用拼布的几何规则而不做核对。

这些材料的缩放范围为 0.25～2、单面透明、BlendMode 为 12。基础贴图 RGB 并不均匀，alpha 字节范围为 150～158，对应着色器的基础不透明度约 **0.3112～0.3489**。模型透明度、距离淡出与渲染排序也会影响画面。

## 配方估算流程

`tools/build_material_candidates.py` 逐纹素计算：纹理线性化 → 对比度曲线 → 材质染色与掩码 → 与底色按 alpha 混合 → 中性显示变换。不能直接把贴图的平均颜色、平均透明度相乘；两者可能相关。

底色校正的分段曲线使用实际参数 `BaseColor_ContrastAdjust × 0.1`。该值为正时指数是 `1 + value`；线性颜色小于 0.5 的分支为 `0.5 × (2c)^exponent`，另一侧为 `1 - 0.5 × (2(1-c))^exponent`。再乘材质染色与强度，按 MRE 的 alpha 掩码与原色混合。估算采用单位模型色和单位白光，未计算高光与场景反射。

对 71 个拼布底色分别叠一层六类材料，得到 426 个候选组合。其中 **421 个中性模型 RGB** 与已有 412 个值不同。该计数描述中性模型中的候选差异，不代表已完成833种颜色的游戏验证。微缩布局仍需独立的几何与透明覆盖适配。

研究结果在 `material-candidates.json`：每种材料保留实际规格、资源编号、纹理范围、基础透明度范围、各底色上的估算值和资源哈希。默认配色使用基础拼布资料；扩展材料通过独立的**可关闭试验选项**参与自动比较。

从本地资料重新生成：

```sh
python -m pip install numpy Pillow texture2ddecoder
python tools/build_material_candidates.py --tables ./table-assets --assets ./material-assets --palette data/furniture_palette.json --output docs/material-candidates.json --runtime-output data/experimental_materials.json
```

表格根目录需包含家具信息表和表现资源表；材料根目录按报告 `resources` 的相对路径准备模型、挂点、材质和纹理。生成器核对真实条目和两种规格，任何不支持的着色器或参数变化会中止。

## 适用条件

- 透明层会透出其他家具；微缩布局依赖重叠遮挡，直接叠加透明材料可能引入相邻区域的颜色。
- 部分材料有纹理、粗糙度和反射，单一 RGB 只能表示受控条件下的估算。
- 单面材质需要保证观察面正确；观察方向需与可见面一致。
- 异形板不能无缝覆盖正方格；覆盖计算应使用实际轮廓。
- 石板、木板和七巧不透明板还带明显纹理或不同着色器，其纹理平均色不作为纯色家具的替代数据。

## 试验配色的分区与遮挡控制

试验配色用于墙面微缩图案。保留不透明的高精度底层，在它前方放置合法最小规格的琉璃片；玻璃分区与采样格对齐，并重新选择分区下面的底色。透明片按分区布置，并保持资源允许的缩放范围。

五种方形材料以0.5米分区比较。玄雾从实际网格读取正面三角形，在2米×0.5米的独立区域中比较；弧线和斜边外的空缺保持原底色。任何两个透明片都不允许覆盖同一条验证射线。

每个像素有九条正面射线。预览由最终蓝图中的资源、坐标、缩放和遮挡重建，颜色使用中性材质平均值；未重放纹理的具体UV、高光、阴影或游戏透明排序。真实蓝图和预览同时验证，但游戏实际颜色仍未确认。

核心调用：

```ts
exportImage(image, { orientation: 'wall', longEdgeM: 8, experimentalMaterials: true });
// 只用于生成对照：保留评分最好的扩展材质候选，即使它没有优于原方案。
exportImage(image, {
  orientation: 'wall',
  longEdgeM: 8,
  experimentalMaterials: true,
  experimentalSelection: 'candidate',
});
```

默认试验策略比较色差、细节与颗粒评分，扩展材质没有改善时恢复完整基础方案，包含原网格精度。`candidate` 是明确的研究对照模式，不能把它的结果当成自动推荐。两种模式都核算玻璃和基座的真实数量，不能超过用户预算。

网页“更多选项”中的“试用彩色琉璃配色”使用默认改善策略，初始关闭。试验要求墙面、长边为0.5米倍数且网格足够细；其余场景继续使用普通导出。

## 可复现的试色蓝图

运行：

```sh
node --import tsx examples/export-material-board.ts
```

输出真实的 `.blueprintx`、说明和 ZIP。试色板包含六种底色，每行先放底色对照，再分别覆盖六类透明材料。透明材料只覆盖中间一部分，便于看出同一环境下的差异；玄雾保留真实异形。

试色板提供序列化往返、编号、缩放和位置检查。**游戏导入与实景颜色不属于自动验证范围**；中性估算不能代替实景校准。不同材料或布局需要各自的几何适配与可见性检查。

## 配色评估

配色评估应固定场景条件，比较深青、暗红、肤色、紫色和中性灰，同时核算色差、纹理噪声与家具用量。配方数量不等于质量；颜色接近或产生杂点的组合不应仅因数量更多而入选。

评分记录中的 `comparisonGrid` 表示材料比较所用的对齐网格；`outputUsesOriginalLayout` 为真时，输出恢复基础布局，最终尺寸与格数以 `summary` 为准。
